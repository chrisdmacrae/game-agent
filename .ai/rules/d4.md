# D4

## Paragon allocation is a path in pre-rotation grid coordinates
paragon[].nodes are 0-based {row, col} into the board grid BEFORE rotation, and attach.gate names the gate cell the board is entered through (attach.to = earlier entry index; the start board has neither). Rotation never changes internal adjacency, so D4ParagonGraph and the validator work pre-rotation and only the renderer rotates (tagging cells before rotating the matrix). Start boards are identified by their single gate plus a StartNode* cell — allocation grows from the start node, and the gate is the EXIT toward the next board. Entries without nodes are legacy and stay legal forever; connectivity checks just skip them with a suggestion to use plan_paragon_path. Maxroll planner `nodes` maps by flat row-major index (row = intdiv(i, width)).
